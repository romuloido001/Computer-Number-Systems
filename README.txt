GRADE 7 ICT – SECTION A
COMPUTER NUMBER SYSTEMS SUMMATIVE TEST
======================================

CONTENTS
--------
1. index.html  - Interactive 25-item multiple-choice summative test.

HOW TO USE THE TEST
-------------------
1. Extract all files from this ZIP archive.
2. Open index.html in a modern web browser (Chrome, Edge, Firefox, or Safari).
3. Enter the student's full name. The class/section is prefilled as Grade 7 – Section A.
4. Click "Start Test".
5. Answer all 25 multiple-choice questions.
6. Click "Submit Test" to see the score, percentage, performance remark, and answer review.
7. Click "Download Student Result (.txt)" to save an individual result report.
8. Students should submit their downloaded result file to their teacher.

HOW TO PUBLISH ON GITHUB PAGES
------------------------------
1. Sign in to https://github.com/.
2. Create a new repository (example: grade7-ict-summative-test).
3. Upload index.html to the root of the repository.
4. Open the repository's Settings.
5. Select Pages from the sidebar.
6. Under Build and deployment, choose "Deploy from a branch".
7. Select the main branch and the /(root) folder, then click Save.
8. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.

IMPORTANT NOTES
---------------
- This is a standalone HTML assessment. An internet connection is not required to open it locally.
- GitHub Pages hosting requires a GitHub account and repository.
- Student answers and scores are processed in the student's browser only.
- The test does NOT automatically send results to the teacher or store a central class record.
- Each student must download their own result report and submit it to the teacher.
- The answer key and explanations are displayed after the student submits the test.
- Keep a backup copy of the original files.
